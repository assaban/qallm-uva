Static analysers read code; they cannot run it. So a function can be tidy, secure-looking, and lint-clean, and still produce the wrong answer. QALLM closes that gap by treating each static finding as a hypothesis and letting execution be the judge. Run the examples below and watch it happen.

Every bug above is real and reproducible, yet invisible to tools that only read source text. QALLM runs generated tests, confirms which findings are genuine, and re-runs the reproducing test after a repair to prove the fix rather than assert it.
